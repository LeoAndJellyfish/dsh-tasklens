# TaskLens v0.2 实施记录

状态：v0.2.0 实现与本机验收已完成。GitHub 发布记录见仓库发布页。用户已确认架构、前端与摘要表达设计，并授权制作、更新本机安装及 GitHub 发布。

## 实施与验收

1. 建立持久任务图、来源索引、范围版本、执行尝试、验收和用户纠正。增量操作执行身份、来源、权限、循环和版本校验；旧节点持续保存。
2. 建立分段日志、校验和、每 20 次提交的恢复检查点。历史读取按提交恢复，不依赖递归文字摘要；迁移保留 v0.1 原记录。
3. 接入公开来源分批分析、受保护约束、有界上下文、独立历史回填及实时分支。模型调用共用次数和 token 预算；过期响应拒绝提交。
4. 接入事实引用与工作汇报语体，区分报告、计划、检查和用户确认。文字检查失败使用有效事实说明；没有重要变化时保留文字。
5. 实现横向历史进度条、阶段树、避障依赖图、任务详情、来源和纠正入口；验证窄栏与深浅主题。
6. 执行行为回放、恢复、预算、并发及来源修订测试，完成 DSH 中配置模型的真实调用与侧栏验收。
7. 更新文档和构建产物，发布 v0.2.0，更新本机插件并核对加载版本。

## 实现约束

- 默认输入预算为估算 8,000 tokens，使用 DSH 的模型窗口元数据设置上限，固定协议也计入预算。
- 未注册的工具结果相关性判断保留“模型判断”。机器验收采用明确命令和结果解析；用户明确验收及侧栏确认独立记录。
- 历史回填按来源顺序，近期预览与当前更新使用独立分支；完整回填通过后切换，并重放用户纠正。
- 中文读者实验由真实参与者完成。自动回归与模型试运行分别记录，发布材料使用实际测量结果。
