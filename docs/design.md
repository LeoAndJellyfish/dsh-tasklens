# TaskLens v0.2 设计与验证

## 任务图与事实

长期状态采用目标、阶段、任务、依赖、需求版本、验收条件、尝试、来源、事实、用户纠正和事件回执。宿主分配稳定标识；模型提交增量操作。省略节点维持原状，撤回与替换保留原节点和理由。

需求扩大产生新的 scopeRevision，旧验收继续保存在旧版本。完成要求当前版本的必需验收均通过。机器验收检查命令与产物绑定、调用标识、调用及结果时间范围、退出码与失败计数；用户验收匹配明确对象和接受措辞。否定验收、设计赞扬、无关命令和 turn/end completed 均保持原有验收边界。

候选事实和文字单元分别引用来源与事实。助手报告、未来计划、已核验结果和明确用户决定分别处理。已发生的结果保留 action:null；用户待办仅来自尚待回答的明确请求。命令与路径在工作概况中采用已绑定任务名称，原命令保留在技术详情。表达校验失败时采用已验证事实生成备用说明，避免增加润色请求。

## 上下文组织

单次输入预算包括协议、JSON 和模型元数据的保守估算。受保护要求整组载入；新增来源逐片排队；相关任务及前置节点、当前验收和近期尝试进入工作窗口；其他任务提供精简目录。完整图、尝试及历史保存在本地。

已载入记录中的来源摘录允许再次引用。宿主同时校验当前来源哈希、原文连续摘录、模型实际看见的摘录边界及历史截止点。模型可以请求节点、原文或本地关键词补充，每批最多一次补充与一次结构修复。

受保护要求超出预算时，完成、范围撤回及版本更新暂存待核对。v0.2 尚未实现跨多个模型请求的完整约束分组验证；页面提供未载入数量与输入预算设置。旧要求采用追加保存，撤回成果在任务状态中记录。

DSH 的 append-origin 记录提供原始公开对话。surface replacement 服务于执行模型压缩，插件排除这些替换副本并保留原用户要求。真实公开来源被修改或缺失时，相关事实与验收失效；历史切面仍保留当时的记录。

长历史采用近期视图与独立回溯代次。回溯完成后核对目标、任务标识并重放用户纠正；对应歧义显示待核对。历史切面按原提交恢复，来源缓存保留引用版本。匹配歧义仍可能需要用户纠正。

## 调度与持久保存

新对话默认 paused:true，v0.1 迁移也默认暂停。用户主动开启当前对话后自动调度，设置按会话持久保存；其他对话维持暂停。仅生成一次不会开启自动解释或连续回溯。重启后的事件先读取本地开启状态。

开启后采用事件去抖、默认 90 秒间隔、30 秒最短间隔和最多两个会话并发。静止记录跳过调用。手动生成、历史回溯、失败和修复共用滚动小时调用与 token 预算。调用前预留输入估算和输出上限，实际 usage 返回后更新计数；未返回用量时保留估算。

追加日志包含提交链、校验和与事务标识，head 原子切换，每 20 个磁盘提交保存恢复检查点。崩溃尾部重放、版本 CAS 和进程租约防止会话过期写入。损坏日志停止覆盖。历史不截断为固定 40 条；浏览器来源分页读取，普通状态轮询复用未变化的路线图。

同一宿主运行时共享小时预算。多个 DSH 独立进程同时写入同一用量文件的全局预算仲裁尚未实现；会话图写入有独立租约与版本保护。

## 前端

页面按目标、当前重点、需要用户处理、阻碍、阶段任务、详情和分析范围排列。标题、状态与重点使用字号、字重、语义色和图标。横向原生 range 支持键盘历史选择。

依赖路线采用固定端口和正交避障，圆角路径为卡片、标题和端点预留余量。小于 540px 时使用纵向路线；大量任务显示阶段入口或选中任务的局部关系。无法避障的关系以文字提示并在任务详情显示前置任务。亮暗主题采用 DSH 变量。

用户纠正支持名称、状态、阶段、前置任务、合并与拆分，绑定页面提交版本和需求版本。历史视图展示当时状态，纠正需返回当前版本。

## DSH 接入

兼容环境：桌面 DSH 0.2.0-rc.2。sidebarRightTabs、sidebar.right.pane.tab 与 conversation.session.header.actions 提供原生入口；客户端采用 DSH 模块加载格式并复用宿主 React。

该版本 connection.rpc.handle 存在 webServer 注入上下文问题。插件注册独立 HTTP 路由，沿用 connection.requestRejection 的身份与来源检查。JSON RPC 请求上限 64 KiB，保留原 401/403 拒绝结果。插件更新后重启宿主以重新加载模块。

## 验证范围

- TypeScript、生产构建与 88 项行为测试：暂停、单次生成、重启开启状态、并发、预算、退避、版本、来源修订、循环依赖、用户纠正、恢复与真实 HTTP 身份检查。
- 20 组固定事实表达案例：数字、范围、报告身份、计划、用户请求与禁用模板。案例为合成回归数据。
- 10,000 事件与 500 节点有界输入；1,000 次历史尝试的工作窗口压缩；超过 40 个历史提交可恢复。
- DSH 已配置 deepseek-official/deepseek-flash：六阶段合成对话覆盖初始路线、失败与重试、局部通过、撤回与改版、报告性完成、明确用户验收。结构错误接受有限修复，既有有效图保持完整。
- 正式 React 组件的 736px、480px、320px、亮暗主题、横向历史选择、来源展开、任务纠正与大图入口检查。

验证使用合成任务记录，未进行真实用户理解度研究。自然语言事实及任务对应仍依赖模型判断，来源和版本校验负责约束其可接受范围。
